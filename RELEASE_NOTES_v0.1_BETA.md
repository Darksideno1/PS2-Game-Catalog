# PS2 Game Catalog — USER v0.1 BETA

First public beta of the portable **PlayStation 2 Game Library** for Windows 10 / 11 (64-bit).

## What's Included

- Game catalog with regional releases, disc serials, and region/language filters
- Personal Physical and Digital game collections, including multiple copies
- Condition and completeness tracking for physical games
- Digital file sizes and Dashboard summaries
- Optional local front-cover images and missing-cover placeholders
- SQLite backup and restore, import/export, Settings, and Help
- English WPF interface with portable local data storage

## Installation

1. Download **`PLAYSTATION_2_GAME_LIBRARY_USER_v0.1_BETA.zip`** attached below.
2. Extract all files to a writable directory.
3. Run **`USER\PlayStation2GameLibrary.exe`**.
4. Keep the `Data`, `Config` and `Media` directories together with the `USER` folder.

This is a self-contained x64 package and does not require installation of the .NET runtime.

## Updating

Back up **`Data\catalogue.db`** first. When replacing application files, **do not overwrite or delete your personal `Data`, `Config`, or `Media` folders**.

## Scope

This release contains **USER only**, with no ADMIN executable or maintenance interface. Front-cover images are not included in the public ZIP.

**Status:** Beta — continue using backups and report any issues you discover.
